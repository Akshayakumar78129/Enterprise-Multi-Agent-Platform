## 🔄 Example Conversation Flows

### **Scenario 1: Understanding a Revenue Drop**
```
You: *[clicks March data point showing revenue drop]*
Chatbot opens with context: "I see you clicked on 2024-03-01 showing revenue: $45,000 (-13.5%)"

You: "Why did revenue drop so much in March?"

@sales responds:
• **Key Finding**: Revenue dropped 13.5% in March vs February ($45K vs $52K)
• **Historical Pattern**: March typically shows 10-15% seasonal decline
• **Context**: March 2024 performance still 9.8% better than March 2023 ($41K)
• **Root Cause**: Post-holiday market adjustment and B2B planning cycles
• **Seasonal Factor**: Winter-to-spring transition affects consumer spending
• **Recommendation**: Focus on April rebound - historically shows 20-30% recovery
```

### **Scenario 2: Customer Analysis**  
```
You: "@customer analyze our retention patterns"

@customer responds:
• **Current Retention**: 78% customer retention rate this quarter
• **Trend Analysis**: 5% improvement vs last quarter (73%)
• **High-Value Segments**: Premium customers show 92% retention
• **Risk Segments**: Budget segment retention dropped to 65%
• **Seasonal Impact**: Q1 typically shows 8-10% retention decline
• **Key Drivers**: Product satisfaction (85%) and support quality (91%)
• **Recommendation**: Focus retention campaigns on budget segment
• **Next Action**: Implement loyalty program for at-risk customers
```

## ❓ Troubleshooting

### **Chatbot Not Opening?**
- Check if you clicked the blue 🤖 button
- Try refreshing the page if there are any loading issues

### **Agents Not Responding?**
- Ensure you have an active internet connection
- The AI service may take a few seconds to respond
- Try rephrasing your question if you get an error

### **@Mentions Not Working?**
- Make sure to type `@` followed by the agent name
- Use the dropdown suggestions for accurate agent names
- Check spelling: `@sales` not `@sales agent`
